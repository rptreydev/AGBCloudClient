# AGB Cloud Client v0.1.0-alpha.7 — Release Notes
> Released: 2026-03-19

## New Features

- **Mute / Unmute Notifications from tray menu** — Right-clicking the tray icon now shows a "🔔 Mute Notifications" item. When active, changes to "🔕 Unmute Notifications". While muted, no Windows toast notifications are shown for downloaded files. The preference is persisted in `progress.json` and survives app restarts. Company-assignment toasts are not affected (those are always shown).

- **Activity tab in Status Panel** — The status panel now has a third tab "🕐 Activity". It shows the last 20 files downloaded by the sync engine, with file name, folder path, size, and a time-ago label (e.g. "3 min ago"). Entries are ordered most-recent-first and updated live as the engine syncs. An empty-state placeholder is shown when no files have been synced yet in the current session.

## Notes

- No configuration migration required — existing `config.json` is fully compatible.
- `progress.json` gains two new fields (`notifications_muted`, `activity_log`) — old versions read it as defaults (muted=false, log=[]).
- 73 unit tests — all passing.
