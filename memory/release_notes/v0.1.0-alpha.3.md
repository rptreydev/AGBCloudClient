# AGB Cloud Client v0.1.0-alpha.3 — Release Notes
> Released: 2026-03-19

## What's New

- **Download activity tracking** — Every time the app downloads a file from the server, the event is now reported to the backend activity log with file name, size, machine, and project/company/location context. Administrators can view the full download history per app in the admin panel under App Distribution → AGBCloudClient → Activity Log.

## Notes

- No configuration migration required — existing `config.json` is fully compatible.
- This is a revision of `0.1.0-alpha.2` released the same day.
