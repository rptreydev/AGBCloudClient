# AGB Cloud Client v0.1.0-alpha.1 — Release Notes
> Released: 2026-03-19

## What's New

- **Automatic updates** — When a new version is available the app downloads and installs it silently in the background. A progress window shows each stage (Downloading → Installing → Done) and cannot be skipped for mandatory updates.
- **Company notifications** — When your supervisor assigns or removes a company from your account you receive an instant desktop notification. No restart needed.
- **Installation & update tracking** — The system now registers when the app is installed, updated, or uninstalled, so your administrator can see which machines are running which version.

## Improvements

- **Session restore** — Fixed a bug where the app could appear logged out on startup even with a valid session. The stored credential is now validated against the server before being accepted.
- **Adaptive status panel** — The status panel (bottom-right overlay) now scales its size to your screen resolution instead of using a fixed size. Works correctly on small laptops and large monitors.
- **Sync pauses automatically** when a company is removed from your account and resumes normally on the next cycle.
- **Installer cleanup** — The temporary update installer is automatically deleted after a successful upgrade.

## Bug Fixes

- Fixed: app did not quit immediately when "Quit" was selected from the tray menu in some scenarios.
- Fixed: uninstaller now correctly notifies the server before removing credentials.

## Notes

- No configuration migration required — existing `config.json` and `sync_state.json` are fully compatible.
- `isMandatory` flag supported: if the server marks an update as mandatory, the update window cannot be dismissed.
