# AGB Cloud Client v0.1.0-alpha.5 — Release Notes
> Released: 2026-03-19

## Improvements

- **Version always visible** — The installed version number now appears in three places: the tray icon tooltip (hover to see `v0.1.0-alpha.5 — Idle`), the Status panel user card (small label below username), and all tooltip states (Syncing, Error, Up to date). Makes it easy to confirm which version is running at any time.

## Notes

- No configuration migration required — existing `config.json` is fully compatible.
- This is a revision of `0.1.0-alpha.4` released the same day.
