# AGB Cloud Client v0.1.0-alpha.6 — Release Notes
> Released: 2026-03-19

## Bug Fixes

- **Fixed: new folder selections from Settings did not trigger sync** — Saving folder selections in Settings → Folders now immediately signals the sync engine to start downloading the newly selected folders. Previously, the engine would only sync on a WebSocket event or app restart; now it wakes within 5 seconds of clicking Save.

- **Fixed: Folder Manager and Settings windows stayed open after quitting the tray** — When the tray was closed via "Quit App", any open Folder Manager or Settings window would remain visible and become unresponsive. Both windows now check for the tray shutdown signal every second and close automatically.

## Notes

- No configuration migration required — existing `config.json` is fully compatible.
- This is a revision of `0.1.0-alpha.5` released the same day.
