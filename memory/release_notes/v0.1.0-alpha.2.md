# AGB Cloud Client v0.1.0-alpha.2 — Release Notes
> Released: 2026-03-19

## Bug Fixes

- Fixed: Installation and update events (INSTALLED / UPDATED / UNINSTALLED) were not being recorded in the backend due to a mismatched app identifier. The system now correctly links events to the registered app.
- Fixed: Automatic update notifications via WebSocket were silently ignored — the app version and update details were not being read from the correct location in the server payload. Updates will now be detected and displayed correctly.
- Fixed: The startup version check (HTTP) was using the wrong app identifier, causing the check to always fail silently.

## Notes

- No configuration migration required — existing `config.json` is fully compatible.
- This is a revision of `0.1.0-alpha.1` released the same day. No new features.
