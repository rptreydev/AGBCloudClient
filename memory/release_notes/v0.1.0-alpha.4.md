# AGB Cloud Client v0.1.0-alpha.4 — Release Notes
> Released: 2026-03-19

## Bug Fixes

- **Fixed: automatic update fails with "Unsupported 16-bit Application" error** — The update installer was downloading an authentication error page (68 bytes) instead of the actual installer file, because the download request was sent without authentication. The app now correctly includes the session token when downloading the update, so the full installer is received and executed properly.

## Improvements

- **Update window can now be dismissed** — The "Update Required" window is no longer locked on screen. A "Remind me later" button allows closing the window; the update notification will appear again on the next launch. The update is still strongly recommended but no longer blocks the screen until installed.

## Notes

- No configuration migration required — existing `config.json` is fully compatible.
- This is a revision of `0.1.0-alpha.3` released the same day.
